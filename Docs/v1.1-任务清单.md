## 验证依据

- 临时 CLI 验证：86 个断言通过，覆盖控制器相关行为；结果属于模拟验证。
- 相关 Go 既有测试、vet 和 App 编译签名校验通过。
- 已有真实网络验证包含授权内网 HTTP 200 和公网验证端点 HTTP 204；最终候选包结果单独记录。
- UI 使用正式应用进行 computer-use 走查；最终 SwiftUI 表单与当前布局的复测记录归入 T07。
- 资源以界面、辅助服务和核心的 physical footprint 总和统计，目标约 50 MB，记录操作后的稳定值。
