## 实施与验证顺序

先完成 T01，再实施局部提示、切换和错误处理；随后补齐删除和菜单操作，最后统一构建与回归。沿用现有测试与人工用例，测试类的新增按仓库约定执行。

网络回归开始前记录当前会话、DNS 和路由基线。使用独立测试时段及授权测试记录，测试结束恢复原网络状态。模拟错误优先覆盖锁定、保存失败和清理失败，减少真实账号尝试。

## 完成记录格式

每项任务记录：对应提交、涉及文件、用例编号、实际结果、证据位置、剩余问题。用例状态使用“待执行 / 通过 / 失败 / 阻塞”。构建通过与交互、业务结果分别记录。
