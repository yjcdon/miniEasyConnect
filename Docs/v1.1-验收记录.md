## 1. 最终实现范围

- AppKit 管理主窗口和 NSStatusItem，SwiftUI 提供主界面、连接表单与验证页。
- 主窗口 480 × 540 pt，状态区 216 pt，状态簇居中；记录区位置与高度固定。
- 大图标统一连接、取消和断开；其他记录可显式切换。
- 新增、修改、删除为统一 28 pt 图标按钮；新增/修改灰底、删除红底，上下操作对齐。
- 表单仅保存；地址、账号、密码和备注持久化后，由独立入口发起连接。
- 删除确认左取消、右红底删除；Return/Escape 取消。
- 后台运行、菜单栏移除偏好、退出清理沿用既有连接能力。

## 3. 实机与网络证据

正式 App 经 computer-use 验证：大图标连接、取消和断开；表单输入、字段错误焦点、密码显隐与仅保存；记录修改、删除确认及 Return 取消。删除确认实际显示左侧取消、右侧红底删除。合成验证记录已删除，正式连接记录保留。

最终包实际连接后，授权内网请求 HTTP 200，公网验证端点 HTTP 204。关闭主窗口后内网仍返回 200，重新打开显示已连接。最后一次 ⌘Q 后界面、辅助服务与核心进程均退出，Wi-Fi DNS 偏好与连接前一致。随后重新启动并连接。

菜单栏移除保持应用运行已在本轮实现中验证；最终包沿用该原生 NSStatusItem 路径。当前外观实测为深色。上述结果证明当前设备和服务端上的功能，不代表跨系统或长时间压力测试。

## 4. 资源记录

按用户后续要求，以约 50 MB 为优化方向，功能优先。统计界面、辅助服务和核心的 physical footprint 合计，MB 为十进制；CPU 为单核心百分比。界面使用 proc_pid_rusage 字节值，特权进程采用 top 的二进制取整单位换算。

| 场景 | 样本 / 时长 | 合计内存均值与范围 | CPU |
| --- | --- | --- | --- |
| 最终包已连接，窗口打开 | 6 / 31.43 秒 | 59.32 MB；58.13–59.69 MB | 0.64% |
| 最终包已连接，窗口关闭 | 3 / 17.68 秒 | 57.90 MB；57.85–57.99 MB | 0.06% |

本次稳定连接约 58–60 MB，未达到严格低于 50 MB。此为短时采样，不能推断长期运行、表单交互或传输峰值。核心采用域名后缀索引、登录后一次释放临时内存及两个 Go 调度工作线程；真实保活和连接协议保持完整。
