## 1. 版本目标

连接操作直接，界面保持简洁。稳定连接时，界面、辅助服务和核心的 physical footprint 合计以约 50 MB（十进制）为目标，优先保证功能与稳定性。窗口打开、窗口关闭和表单操作后的占用分别记录；启动与持续传输峰值单独观察。

源码版本为 1.1.0，构建号为 4；最低构建目标为 macOS 13、Apple Silicon，当前实测系统为 macOS 27.2。公开下载仍为 v1.0.1。

### 窗口与界面

主窗口固定为 480 × 540 pt。上方状态区为 216 pt（40%），下方记录区占其余空间（约 60%）。状态内容整体居中；授权和失败状态按需展示操作，分隔线位置与记录区可用高度保持固定。较长状态说明在状态区内部滚动。

新增、修改和删除复用 28 × 28 pt 图标按钮。新增与修改为灰底，删除为红底；新增按钮与列表删除按钮的中心线对齐。悬停和辅助功能标签表达实际动作，长备注与地址提供完整内容提示。

连接表单使用 SwiftUI，包含地址、账号、密码和最后一项可选备注。字段标签始终显示，占位文字和辅助说明保持空缺。密码显示切换位于输入框内部，提交区域为“取消”“保存”。

### 连接状态与异步边界

控制器持有用户连接意图、实际快照、最近使用记录、切换目标及编辑错误。界面根据真实快照显示“未连接”“正在连接”“已连接”“正在恢复连接”“正在断开”“连接失败”等状态。

切换时先设置目标、停止旧会话，再启动新会话。取消会清除目标和重连意图；晚到的断开回复通过当前目标与用户意图检查。普通连接命令共用启用条件，大图标在可取消的过程中仍提供取消动作。验证码保留既有验证页及取消路径。

## 3. 保存与数据一致性

统一表单调用 saveConnection，使用 ProfileStore 校验地址和账号，按既有顺序写入钥匙串与 JSON。保存成功更新列表并关闭表单，最近连接标识在显式发起连接时更新。

修改活动记录时，当前 activeProfile 与 desiredRequest 仅同步备注，保留正在使用的连接身份、密码和证书信任。保存的新地址或凭据用于下一次显式连接。连接失败后修改密码并保存，再点击“重试连接”时读取最新记录及钥匙串；系统授权后的继续连接保留原请求。

保存失败留在表单并保留输入；字段错误就近显示并聚焦。新记录已保存、旧凭据清理失败时，提示实际保存结果与清理问题。JSON、钥匙串及偏好格式沿用既有约定，独立备注编辑由统一表单承接。

## 4. 删除确认

确认前检查记录是否为活动连接；执行删除时再次检查最新状态。确认页采用固定水平布局：左侧“取消”，右侧红底“删除”。Return 与 Escape 均执行取消。取消保留记录和凭据；确认后完成记录及对应凭据删除。删除失败留在确认页并显示原因。

## 5. 窗口、菜单与生命周期

AppKit 持有 ConnectionController 和主窗口，按需创建承载 MainView 的 NSHostingView。普通关窗释放 hosting；存在编辑、验证或确认上下文时保留相应界面状态。Dock 重开与菜单“打开”恢复主窗口；后台需要输入或处理错误时打开窗口。

菜单栏使用 NSStatusItem，仅启用 removalAllowed。手动移除图标改变可见性偏好，应用与连接保持运行；应用菜单可恢复图标。KVO 与 Combine 回调采用弱引用，订阅在对象销毁时清理。

应用菜单提供新建（⌘N）、连接最近记录、断开、显示菜单栏图标、停用服务和退出；系统编辑菜单提供复制、粘贴、剪切、撤销与重做。⌘Q 等待停止连接及网络恢复结果后退出。

关闭窗口和结束编辑各触发一次延迟的 allocator 空闲页归还，最多保留一个待执行任务，再次编辑时取消。重连任务沿用次数与间隔上限，网络变化通过事件通知处理。

## 6. 核心与网络

辅助服务维持唯一核心会话，沿用现有 XPC、网络恢复和 DNS 处理。核心以 GOMAXPROCS=2 运行，域名索引使用后缀 map；登录完成后一次性归还闲置内存。资源效果以全进程实测为准。

恢复记录写入前确保父目录存在，以支持活动期间目录被清理后的正常恢复。主动断开、取消与退出继续使用已有恢复流程。
