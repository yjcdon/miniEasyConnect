## 1. 版本目标与范围

让连接目标、操作结果和错误处理更清楚，保持“大图标、连接状态、连接记录”的主界面，以及点击一次发起连接的操作路径。稳定连接时，界面、辅助服务和核心的 physical footprint 合计目标为 50 MB 以下（十进制）；窗口打开与关闭分别验证，启动峰值与传输负载单独记录。

本版覆盖五项功能，编号以 V11 为前缀，与主产品功能编号区分：

| 编号 | 功能 | 最终行为 |
| --- | --- | --- |
| V11-F01 | 大图标提示 | 悬停显示即将连接的记录，点击沿用最近记录连接；首次使用点击创建记录 |
| V11-F02 | 切换连接表达 | 已连接时，其他记录的按钮显示“切换”；点击直接开始切换，过程显示目标记录 |
| V11-F03 | 错误反馈归位 | 连接错误在状态区处理，输入错误在对应字段处理，记录管理错误保留操作提示 |
| V11-F04 | 删除前置判断 | 当前活动记录先提示断开；可删除记录进入原有二次确认 |
| V11-F05 | 菜单辅助操作 | 应用菜单提供新建、连接和断开；图标补充悬停提示 |

主窗口继续使用现有 480 × 540 布局、状态名称、记录顺序及大图标。窗口缩放、菜单栏状态图标改造、验证码体验调整列为后续候选。最低部署目标沿用 macOS 13、Apple 芯片；HIG skill 中的通用建议服从项目已有兼容约定。

## 3. 系统职责与数据

改动集中在 SwiftUI 应用层。辅助服务、Go 核心、XPC 消息、路由与 DNS 处理沿用现有实现。

- `ConnectionController` 持有真实连接快照、最近使用记录、切换目标及错误展示归属，并提供统一的命令可用条件。
- `MainView` 根据这些状态渲染按钮、悬停提示和字段错误；保留现有布局与输入值。
- `MiniEasyConnectApp` 的应用菜单和菜单栏复用控制器动作，保证鼠标与键盘触发相同业务行为。
- `ProfileStore` 继续负责记录与凭据存储。文本编辑沿用系统复制、粘贴和撤销操作。

新增状态仅驻留内存：

| 状态 | 业务含义 | 生命周期 |
| --- | --- | --- |
| 切换目标记录 | 用户刚刚选择、等待旧连接清理后启动的记录 | 切换开始至目标启动、旧连接清理失败或用户取消 |
| 编辑错误及字段位置 | 当前输入需要修正的原因与位置 | 提交校验、修正字段、关闭编辑页 |

本地记录 JSON、钥匙串引用、最近记录和菜单栏显示偏好的存储规则保持兼容。切换目标与真实活动记录分别表达；“已连接”继续由辅助服务快照确认。

## 5. 详细交互与异常处理

### 5.1 大图标

未连接或失败且允许连接时，悬停提示为“连接：记录名称”；无记录时为“新建连接”。提示与辅助功能标签使用同一目标来源。悬停增加轻微背景或描边反馈，键盘焦点保持清晰，使用现有尺寸。已连接及处理中显示与当前状态一致的标签。

### 5.2 切换流程

1. 已连接 A 时，B 的按钮显示“切换”；未连接时显示“连接”。
2. 点击 B 后，控制器记录切换目标 B，沿用原流程停止 A；状态区显示 B 的名称作为切换目标，A 的实际状态仍由快照决定。
3. A 清理成功后启动 B，进入原有连接状态流程。B 的“已连接”以服务返回的就绪快照为准。
4. A 清理失败时展示该失败原因，并清除切换目标。后续处理依据实际会话状态提供断开或重试路径。
5. 用户取消或退出时，清除切换目标，并沿用现有停止意图处理，避免晚到回调启动 B。

切换期间已有连接入口统一禁用。目标文字放在已有状态描述区域；列表维持原顺序。

### 5.3 错误展示归属

| 错误来源 | 主要展示位置 | 处理方式 |
| --- | --- | --- |
| 地址格式、账号或密码输入校验 | 相应字段下方 | 保留输入，聚焦首个错误字段；字段修正后重新校验 |
| 读取密码失败 | 编辑页密码区域 | 保留地址、账号、备注，提示重新输入或解锁钥匙串 |
| 保存记录失败 | 编辑页提交区域 | 保留输入，修复后再次提交 |
| 认证拒绝、账号锁定、连接超时、切换清理失败 | 主窗口状态区 | 保留现有准确分类及可用处理动作；同一次失败采用单一主要反馈 |
| 删除、备注保存、后台服务管理失败 | 原操作所在编辑页或操作弹窗 | 保留对象上下文，提供具体原因 |
| 退出时恢复网络失败 | 可见的操作弹窗 | 退出保持待处理结果，让用户能重试恢复；窗口关闭时同样可感知 |
| 新记录已保存但旧凭据清理失败 | 保存结果提示 | 表达实际保存成功及清理问题，继续沿用存储结果处理 |

由命令种类、当前操作及已有结构化错误判断归属，避免按提示文本内容猜测错误类型。更新 `perform` 前核对连接、断开、认证回答、退出和停用服务所有调用点。状态区较长错误通过现有区域换行或局部滚动完整可读，列表和处理按钮保持可达。

### 5.4 删除

当前活动记录收到删除操作时，先给出“请先断开当前连接，再删除记录”的提示。普通记录继续使用原生确认框，默认焦点为取消。删除入口保留执行时状态检查，覆盖确认期间状态变化；取消操作保持记录与钥匙串内容。连接过程中继续沿用记录菜单的禁用规则。

### 5.5 菜单与键盘

- 应用菜单增加“连接”分组：新建连接（`⌘N`）、连接最近记录、断开连接。只有新建分配本版快捷键，其他命令通过系统菜单访问。
- 新建与连接命令在忙碌、连接编辑页、备注编辑页或验证页打开时暂停；断开命令按当前连接状态与正在执行的操作启用。菜单栏采用相同可用条件。
- 记录的三个点菜单保留修改备注、修改连接和删除；密码由密码输入框的显示切换负责。
- 眼睛、三个点补充悬停说明；长记录名称和地址提供完整内容提示，VoiceOver 标签保持可读。

## 6. 影响、兼容与资源

主要风险是错误反馈调整影响退出清理，以及切换目标与异步回调不同步。分别通过退出失败可见性、切换失败和取消时序用例验证。

状态展示由现有事件驱动。悬停、菜单和字段校验使用原生能力，预期资源增量较小；以同设备、同连接条件测量确认。编译目标保持 macOS 13 ARM64，实际系统验证结果单独记录。

候选包升级时复用既有应用标识、数据路径与钥匙串约定，验证旧记录和最近连接可读取。回退使用 v1.0.1 包，先正常退出候选版本并完成网络恢复；数据格式保持兼容。

## 7. 验证与交付

按配套测试用例执行源码检查、现有构建及人工交互和网络回归。实际连接使用授权测试环境；错误注入优先使用已有模拟方式，账号锁定通过模拟结果验证。网络测试安排在可中断会话的独立时段。

完成标准：五项功能均有验证记录，单击连接和切换、关闭窗口保持连接、退出恢复网络全部通过。公开文档与截图仅使用虚构记录；执行证据记录用例编号、系统、构建版本和脱敏结果。
